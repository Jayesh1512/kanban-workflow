# Private outreach dashboard

`index.html` is a self-contained, read-only dashboard. It contains private relationship data and is ignored by Git. Open it directly or use the loopback preview supplied in the conversation.

The page shows the five requested CRM stages as a Kanban: Lead / Prospect, Qualification, Negotiation, Deal Won and Archived. Each relationship has a placement reason, source date, contacts and next AntSeed action. These are evidence-derived display classifications; native six-lane Vikunja positions remain available in source history and are not changed.

The evidence comprises the verified 23 October Telegram-derived board snapshot and the user-supplied two-part raviAntBot email report from 25 October. All 38 visible native cards are accounted for: 15 cards form 14 business relationships after merging only the two confirmed Bonfires.ai company chats; 23 other chats remain in context review. Seven email-outreach companies and eight explicitly labelled historical/research leads complete 29 pipeline relationships. Cross-channel company identities are not guessed.

The dashboard provides search, source filters, stage navigation, expandable source history and a visible-pipeline CSV export. No control approves proposals, sends outreach or changes database records. Waiting age is not overdue; trials and bookings are not wins; silence is not an archive decision.

Private collection evidence, source hashes, the build script and the Hermes delivery receipt are in `.local/outreach-dashboard/`. The refresh helper is read-only and does not restart services. The current dashboard is explicitly a saved snapshot; it does not silently claim to refresh itself.
