# Outbound boundaries

Local app, SQLite and connectors run on the team's machine. General inference uses the official hosted OpenAI service; cross-swimlane judgment uses hosted TypeSafe Jev. [OpenAI choice](/Users/jys/Documents/Projects/hello/.context/decisions/2026-10-10-openai-cloud-llm.md) and [Jev choice](/Users/jys/Documents/Projects/hello/.context/decisions/2026-10-10-jev-swimlane-decisions.md) settle those destinations, not account risk, terms, privacy, quality, latency or cost. Neither hosted model is asserted open-source/self-hosted. Offline injected tests are [F] infrastructure checks, not a live-provider or [M] pass.

The production bridges refuse redirects, query/fragment/userinfo/nondefault port/wrong host/path and pass bearer authentication only to the selected named destination. Vercel is an additional processor of Jev movement context; requests are billed through its AI Gateway. No app hosting change is required. Native node:https uses no ambient HTTP proxy or credential configuration; SDK fetch strips other headers. No arbitrary endpoint, public-host switch, local inference or other-provider fallback. The historical private-overlay/100.64/allow-public policy is superseded history. OPENAI_BASE_URL and the four legacy MODEL_* endpoint/name/key/switch controls are rejected. A JEV_ENDPOINT value gives visibility, not permission to call another host. Test transports capture the canonical destination; no production loopback setting exists.

OpenAI configured model is server OPENAI_MODEL, with gpt-6.1-sol selected in the example; the key is OPENAI_API_KEY. No model fallback is chosen by the app. Settings shows api.openai.com, the configured model and a safe blocked reason, never keys. Missing model/key produces no inference request while human and ingestion work continue. General accepted limits: current+20 earlier same-chat messages,10 offered other-chat cards,15 companies;16384UTF8 bytes text+media per message,1MiB complete serialized request/response. The adapter and port enforce scoped context, request/response bounds and output structure. Default output4096/range1..16384, deadline30000ms/range1..60000, per-processing-attempt max2 calls/range1..2. Each decide sends one call; SDK retries0. Schema and transient retries share the per-processing-attempt call budget, with a1000ms injected wait and scheduled30s doubling to5min; this is not a two-call lifetime limit.

The selected Vercel Jev route uses JEV_MODEL=typesafe-ai/jev and AI_GATEWAY_API_KEY. Direct TypeSafe uses a direct jev-* model and JEV_API_KEY only when explicitly selected. Credentials are route-specific: a gateway key is never substituted onto the direct host, and failure never switches routes. See [Vercel’s compatibility documentation](https://vercel.com/docs/ai-gateway/sdks-and-apis/typesafe). The gateway’s top-level model may echo the primary alias; that is not a measured underlying version. Decision fallbacks to other models are not requested and non-Jev substituted responses are rejected. Configured model, supplied resolved version and provider metadata remain separate from general-model status and replay execution; the app does not fabricate missing metadata. Accepted Jev limits:21 evidence messages,4096UTF8 bytes combined text+media per item;64KiB complete state,256KiB COMPLETE request (all questions/templates/options),1MiB response;<=253 transitions plus stay/review, exactly N+2<=255 questions,<=23 support options. Overflow is zero-call context_limit, with no truncation/shortlisting. The adapter and port enforce scope, question, option, state and body bounds plus the deadline. Default deadline10000ms/range1..30000, maxAttempts1/default or2/configured, retries only network/timeout/429/5xx using identical body/hash/questions and1000ms injected wait; total <= attempts*timeout+(attempts-1)*1000ms (max61000). No conditional second support call.

Ports support cancellation and discard late replies. The processing and review paths recheck transactional freshness and permissions, group typed failures and latch unsupported/authentication failures to prevent repeated calls or stale mutations. Request snapshot/hash stays immutable; the app stores separate expected POST-outcome settlement facts, IDs/versions/digests only, never request text/title/summary/raw provider errors. Accepted0002 audit is unchanged. No provider response cache is written. All real hosted authentication/integration, model quality/coverage/calibration, retention/latency/cost and [U] one-hour outbound observation remain untested.
